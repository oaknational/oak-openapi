# Rules for subjects in sequences

1. `subjectcategories` are referred to as "Category"
2. `subject` (if the unit has `subject_parent != null`) is "Exam Subject" (also known as a child subject)

- Categories can apply to to any key stage
- Exam Subjects only apply to KS4
- Learning tiers (higher and foundation) only apply to KS4

If categories or exam subjects or learning tiers are present, exactly one should be selected from each of these to be able to find the unit collection in the sequence.
