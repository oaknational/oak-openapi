# Glossary

Purpose
- Provide shared definitions for common terms used in the API and docs.

Core content terms
- Key stage: a curriculum grouping (e.g., KS1, KS2).
- Subject: a discipline within a key stage (e.g., maths).
- Unit: a collection of lessons within a sequence.
- Lesson: a single teaching session with assets and metadata.
- Sequence: an ordered collection of units (often used as a bulk export boundary).

API and data terms
- Lesson slug: the stable string identifier for a lesson.
- Unit slug: the stable string identifier for a unit.
- API key: credential used to access most API endpoints.
- Rate limit: per-key request limit enforced by Upstash.
- Gating: licensing allow/deny rules for content.

Docs and tooling
- OpenAPI: machine-readable API specification generated from Zod schemas.
- tRPC: framework used to define typed API routes.
- Sanity: CMS used for documentation content.
- Bulk download: offline dataset generated by `bin/prepare-bulk.ts`.
